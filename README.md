# Ficha One Piece - Firecast

Este projeto é uma ficha personalizada para o sistema de RPG de mesa **One Piece**, criada com base no conteúdo do **Sir Brendo** e desenvolvida para ser usada na plataforma **Firecast**.

## 📋 Sobre o Projeto

A ficha foi pensada para facilitar o gerenciamento dos personagens durante as sessões de RPG ambientadas no universo de **One Piece**, oferecendo campos organizados para atributos, perícias, técnicas, vantagens, desvantagens e outras informações importantes do jogo.

Ela busca manter o sistema criado pelo **Sir Brendo**, adaptando sua mecânica para um formato digital e interativo compatível com o **Firecast**.
